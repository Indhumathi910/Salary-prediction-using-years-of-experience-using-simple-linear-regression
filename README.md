# 💼 Salary Prediction App

## 📌 What is this project?

This is a **simple Salary Prediction application** built using **Machine Learning and Streamlit**.

The app predicts a person’s **expected salary** based on their **years of work experience**. It is designed to be **easy to use**, even for **non-technical users**.

---

## 🧠 How does it work? (In simple words)

* A machine learning model has been trained using past data of **experience vs salary**.
* You give your **years of experience** using a slider.
* The app calculates and shows an **estimated salary**.

👉 You don’t need to know coding or machine learning to use this app.

---

## 🛠️ Technologies Used

* **Python** – Programming language
* **Machine Learning (Simple Linear Regression)** – For prediction
* **Streamlit** – To create the web app
* **Joblib** – To load the trained model
* **NumPy** – For data handling

## ▶️ How to Run the App (Step-by-Step)

### 1️⃣ Install required libraries

Open terminal or command prompt and run:

```
pip install streamlit joblib numpy
```

### 2️⃣ Run the application

```
streamlit run app.py
```

### 3️⃣ Use the app

* Move the **Years of Experience** slider
* Click **Predict Salary**
* View your **predicted salary** instantly
